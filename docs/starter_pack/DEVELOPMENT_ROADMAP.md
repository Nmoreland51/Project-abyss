# Project Abyss — Phased Development Roadmap

| Phase | Scope | Exit gate |
|---|---|---|
| 0 — Scientific foundation | Taxonomy, public references, scope, data contracts, baseline plan | Reviewed design and traceability matrix; no invented results |
| 1 — Foundation | Repository, migrations, ingestion, evidence, persistence, minimal CLI | Real accessible sources ingested and restored after restart |
| 2 — Recognition | Documented architecture representations; simple classifier and benchmark | Independent known-family benchmark; error analysis |
| 3 — Unknown recognition | Controlled withheld-family experiments, calibrated novelty, hypotheses | Measured unknown recall and false unknown rate; no unsupported identities |
| 4 — Hidden value | Search accessible obscure repositories and archives; rank practical tools | Independently verified findings absent from starting corpus; baseline comparison |
| 5 — Autonomy | Persistent job queue, scheduling, limits, retry and recovery, dashboard | 24-hour bounded run and failure-recovery demonstration |
| 6 — Improvement | Versioned retrieval/ranking/model iterations | Frozen test results, ablation and rollback demonstration |
| 7 — Release audit | Full regression, provenance, reliability, performance, documentation | All critical defects resolved; 72-hour run; reproducible release |

## Phase execution protocol
1. Inspect repository and record commit, environment and baseline test results.
2. Identify missing requirements and related defects in one audit.
3. Implement a coordinated change set with migration and rollback strategy.
4. Run unit, integration, end-to-end and relevant experimental tests.
5. Record measured results, failed experiments and unresolved issues.
6. Update traceability matrix, status and changelog. Commit only validated work; identify any remaining failures.

## Minimum viable milestone
An accessible-source research pipeline that retrieves actual documentation, records evidence, discovers an obscure useful tool, explains its ranking and recovers from an interrupted job. This proves the product objective before investing in complex novelty models.

## Explicit nonclaims
No phase demonstrates the existence of an entirely unobservable network. A simulated discovery is not a real-world discovery. Unknown model output does not establish a new protocol or criminal activity. Do not claim a milestone passed when only its UI or mock works.
