# Owner decisions register

Decisions that belong to the owner. Each has the default I applied so work could continue, what that
default affects, and the alternatives. Nothing here is a hidden policy: every default is reversible
and listed. **Security requirements** (marked S) are separated from **behavioural/product choices**
(marked B). Legal, rights and distribution obligations are not optional toggles and are not listed
as choices.
