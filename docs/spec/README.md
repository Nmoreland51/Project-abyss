# RetroReddit V2 — Live Platform Development Pack
This is a planning and implementation package, not source code, an APK, or completed test evidence. It replaces the V1 archive/time-machine product with an independent live social network and classic Android client.

Read CODING_AGENT_DIRECTIVE.md first, then MASTER_AUDIT.md, SYSTEM_ARCHITECTURE.md, DEVELOPMENT_ROADMAP.md, DATA_AND_GOVERNANCE.md, TESTING_STRATEGY.md, and REQUIREMENTS_TRACEABILITY.csv. Give the entire directory to your coding agent. Begin with Phase 0 and build the real two-account vertical slice before historical imports. No need for an archive date selector. Historical material is optional and subject to permission. A new server does not inherit Reddit's community or user accounts.

All implementation statuses in the traceability matrix are planned. No APK or runtime tested by this audit.
